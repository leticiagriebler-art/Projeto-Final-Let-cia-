# Portfólio — Letícia Griebler

Bem-vindo ao meu portfólio pessoal!

Este projeto foi desenvolvido para apresentar meus conhecimentos, habilidades e projetos na área de **Informática para Internet**, com foco em desenvolvimento web, UX/UI Design e tecnologia.

---

## Sobre o projeto

Este portfólio foi criado com o objetivo de reunir meus principais trabalhos e apresentar minha evolução como estudante e desenvolvedora.

O site possui uma interface moderna, responsiva e adaptada para diferentes tamanhos de tela.

## Estrutura do projeto

```text
portfolio/
│
├── index.html
```

### `style.css`

* Cores
* Tipografia
* Layout
* Animações
* Responsividade
* Cards
* Botões

### `script.js`

Responsável pela interatividade do site, como:

* Menu para dispositivos móveis
* Formulário de contato
* Animações ao rolar a página

## Design

O projeto utiliza uma identidade visual baseada em:

* Fundo escuro
* Tons de roxo
* Elementos minimalistas
* Cards com efeito de destaque
* Layout responsivo
* Animações suaves

A proposta visual é transmitir uma identidade moderna, tecnológica e profissional.

---

## Responsividade

O site foi desenvolvido para funcionar em diferentes dispositivos:

* Computadores
* Notebooks
* Celulares
* Tablets

O CSS utiliza **Media Queries** para adaptar o layout a telas menores.

---

## Como executar

1. Baixe ou clone este projeto.
2. Abra a pasta no **Visual Studio Code**.
3. Certifique-se de que os arquivos estão na mesma pasta.
4. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** no Visual Studio Code para visualizar o projeto durante o desenvolvimento.
